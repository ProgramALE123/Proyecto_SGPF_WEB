# SGPF WEB

Esta es la copia preparada para publicar. El proyecto local original no fue modificado.

## Publicacion en Render

1. Subir esta carpeta a un repositorio de GitHub.
2. En Render, seleccionar **New > Blueprint**.
3. Conectar el repositorio y confirmar los recursos definidos en `render.yaml`.
4. Al terminar, abrir la direccion `https://sgpf-web-....onrender.com`.

El Blueprint crea PostgreSQL, instala los scripts SQL, construye Angular y publica frontend y backend bajo una misma direccion.

## Ejecucion local de esta copia

La copia web esta configurada para produccion. Para el desarrollo cotidiano se debe continuar usando `C:\5toA\Proyecto_SGPF`.
